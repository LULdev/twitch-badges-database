    How rare is the The Blood of Dawnwalker Launch badge?+

    It scores 54 out of 100 on the TBRI v2, which puts it in the Rare tier. The index is not simply an owner ranking: owner scarcity carries 40% and obtainability 20%, so a badge that was on offer for a single day outranks a permanent badge that far more people hold.

    What do the set ID and version mean?+

    Twitch identifies a badge by a set ID (the-blood-of-dawnwalker-launch) plus a version (1). The set is the badge family; the version is one specific piece of artwork within it. Both are printed because they are the identifiers Twitch's own APIs use — two pages with different versions of the same set are genuinely two different badges.

    How does this site decide the badge status?+

    The status is not guessed. An independent badge index confirms which badges are currently redeemable, and that confirmation deliberately outranks the dates stored in our own row, so a stale end date can never demote a badge you can still claim. The dates are then used only to separate a confirmed badge whose window has not opened yet from one that is open now. The stored figures were last refreshed on October 5, 2026.

    How do I get this badge on my own channel?+

    Twitch badges attach to your account, not to one channel. Once Twitch grants you the badge it appears on every channel you stream from, and it stays there for as long as the qualifying condition holds — a subscription badge survives a gap in your sub month only if you re-subscribe.
